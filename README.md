# Sine Qua Non Est

**Institute for Human–AI Research**

Website: [sinequanone.org](https://sinequanone.org)

## Motto

*Iudicium humanum est condicio sine qua non est scientia.*

Human judgment is the condition without which there is no science.

The name **Sine Qua Non Est** comes from the end of the founding sentence — not invented Latin, but a deliberate extraction from the institute’s full proposition.

## Founding lines

| Latin | English |
| --- | --- |
| *Iudicium humanum condicio sine qua non est.* | Human judgment is the indispensable condition. |
| *Alia via non est.* | There is no other way. |
| *Concordia hominis et machinae condicio sine qua non est.* | Harmony between human and machine is the indispensable condition. |

## Work

This organization publishes research software and tools for human–AI collaboration in science.

- **Kyoei** — A collaboration layer for people and agents: each organization runs its own node; releases are scoped to named organizations and purposes; agents leave signed records of work. A Cloudflare Workers port is in preparation for Cloudflare’s call for a Git platform for agents. It is not published yet.
- **Harnesses for AI-assisted science** — Planned public releases here. No public repository yet.
